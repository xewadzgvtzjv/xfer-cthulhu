## Overview

Cthulhu is a MIDI effect that transforms single notes into chords using a 16-voice chord library, then sequences those chords through a 32-step arpeggiator with velocity and rhythmic modulation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Xfer Cthulhu** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Chord Library** | Store up to 16 custom chords mapped to MIDI keys for instant recall |
| **32-Step Arp** | Arpeggiator with configurable note order, octave range, and swing |
| **Velocity Sequencer** | Per-step velocity lane for dynamic rhythmic variation |
| **MIDI Learn** | Map external controllers to chord trigger keys in real time |
